## 🚀 Featured Projects

### 📦 StockFlow – Distributed Inventory Management System

<text>Java | Spring Boot | Spring Data JPA | PostgreSQL | Redis | Kafka | Docker</text>

- Architected a microservices-based inventory management system consisting of **5 Spring Boot services** with Spring Cloud Gateway and JWT-based authentication.
- Implemented an event-driven order saga using Apache Kafka, transactional outbox, idempotent consumers, and dead-letter topics for reliable stock reservation and compensation.
- Prevented overselling using JPA optimistic locking and retry mechanisms.
- Validated concurrent order processing with **100 concurrent orders and zero negative-stock cases**.
- Integrated Redis caching and containerized services using Docker Compose.

🔗 [View Repository](https://github.com/Bhavdeepmnit)

---

### 👕 T-Shirt Order Management Portal

<text>MERN | React 18 | Socket.io | JWT | MongoDB | Tailwind CSS</text>

- Architected a full-stack role-based application supporting **3 user tiers — Super Admin, Branch Admin, and Student — across 7 MNIT branches**.
- Built a secure REST API with JWT access and refresh tokens, bcrypt password hashing, Joi validation, Helmet security headers, branch-isolation middleware, and rate limiting.
- Implemented real-time Socket.io room-based notifications, branch-wise dynamic pricing, and form-lock workflows.
- Integrated one-click Excel export using SheetJS for dispatch workflows.
- Built a responsive React 18 + Vite frontend with Tailwind CSS, Recharts analytics, and Axios interceptors for automatic token refresh.
- Deployed on Railway with CORS hardening.

🔗 [View Repository](https://github.com/Bhavdeepmnit)
